# PRÁCTICA GIT Y GITHUB

## Descripción
Este proyecto permite practicar el uso de Git y GitHub.

## Objetivo
Aprender a controlar las versiones de un proyecto.

## Herramientas
- Git
- GitHub
- Visual Studio Code
## Aprendizaje

- Aprendí a crear un repositorio.
- Aprendí a utilizar Git y GitHub.
- Aprendí a subir proyectos a GitHub.
## Conclusión

Aprendí a utilizar Git y GitHub para guardar,
actualizar y compartir mis proyectos.
## Funcionalidades planeadas

- Documentar los cambios del proyecto.
- Mantener un historial de versiones.
